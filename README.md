# Customer Purchase Analysis 📊

## 📌 About the Project

**Customer Purchase Analysis** is a data analytics project that analyzes customer purchasing behavior using **Python, SQL, and Power BI**.

The project focuses on customer spending, product preferences, discounts, subscriptions, purchase frequency, and customer segments.

## 🛠️ Tools & Technologies

* **Python** – Pandas, NumPy, Matplotlib, Seaborn
* **MySQL** – SQL queries and analysis
* **Power BI** – Interactive dashboard
* **Excel** – Dataset
